Selected work

Projects and case studies

Data Preparation / Churn Prediction

Telco Churn Analytics

An end-to-end churn analytics project using messy telecom customer data. The workflow audits and cleans data quality issues, validates service and billing fields, performs EDA and statistical testing, and compares leakage-safe sklearn models with an optional deep learning baseline.

View Case Study → GitHub Repo →
Machine Learning / Churn Benchmarking

Telco Churn ML Benchmarking

A machine learning benchmark on the Telco churn dataset comparing logistic regression, random forest, gradient boosting, KNN, decision tree, and tuned XGBoost. The project adds PCA, threshold analysis, calibration, ROC-AUC evaluation, and permutation-importance interpretation to select a defensible churn model.

View Case Study → GitHub Repo →
Fairness Research

League Matchmaking Fairness

A data-driven League of Legends matchmaking analysis comparing ME1 and EUW1 ranked matches using over 230,000 archived matches. The project studies rank variance, autofill rate, win prediction accuracy, and regional fairness indicators.

View Case Study → GitHub Repo →
Healthcare AI / Computer Vision

CholecTrack20 Benchmark

A surgical AI benchmark comparing YOLO11 and EfficientDet-D0 detector baselines with EA-StrongSORT tracking on CholecTrack20 video data. The project focuses on detector evaluation, multi-object tracking, benchmark reporting, and reproducible computer vision workflows.

View Case Study → GitHub Repo →
Cybersecurity AI / Big Data

Explainable Edge-IIoT IDS

An explainable, drift-aware intrusion detection system for Edge-IIoT traffic using XGBoost, SMOTE, SHAP, ADWIN drift monitoring, Isolation Forest anomaly overrides, MongoDB evidence storage, and a Streamlit dashboard. The project includes live/PCAP replay verification and dashboard screenshots for model artifacts, predictions, SHAP, drift, retraining, robustness, and latency evidence.
