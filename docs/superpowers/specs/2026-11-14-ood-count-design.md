# OOD stock count

The approved workflow is to import the same Excel stock file, count physical stock into five exclusive expiry windows, see differences against On Hand, print an Excel export and save an independent OOD count history. The >3-month bucket is entered manually so missing units stay visible. Use the existing tablet cards and coordinator vault rather than adding columns to the ordinary Cycle Count or forcing individual batch entries. The existing batch tracker and records remain accessible. Use the checking date and calendar-month guidance with the existing seven-month default; imported files do not provide physical batch expiry. Unfinished rows carry no variance. Match the Cycle Count screen's counted-minus-On-Hand display and the printed export's On-Hand-minus-counted convention, labeling both directions.
