# OOD Stock Count Implementation Plan

> Use superpowers:executing-plans for inline execution. Steps use checkbox syntax.

**Goal:** Count stock by expiry window from the existing workbook and save independent snapshots for review and printing.

**Architecture:** Share Excel import; use a dedicated OOD model and screen inside Coordinator. Save drafts and immutable history in the encrypted vault, validating new records on restore while preserving legacy vaults.

**Tech Stack:** Existing browser JS, IndexedDB, Web Crypto, XLSX and DOM tests.

**Spec:** `docs/superpowers/specs/2026-11-14-ood-count-design.md`.

## Global Constraints

Keep same URL, database and PIN. No dependencies or changes to the Cycle Count export. Use calendar months for window guidance. Keep the existing batch tracker.

## Review Focus
